# 몹 탐지 모델 학습

게임 화면에서 몹(`monster`)과 내 캐릭터(`me`) 위치를 찾는 YOLO 모델을 학습한다.
캡처와 라벨, 학습 결과는 모두 `%USERPROFILE%\.baram_macro` 아래에만 두고 저장소에는 올리지 않는다.

## 1. 캡처 모으기
주술사 앱 아래쪽 **학습 캡처** 줄에서 `●`를 누르고 평소처럼 사냥한다.
게임 창을 1.5초마다 찍어 `%USERPROFILE%\.baram_macro\dataset\raw`에 저장한다. 직전 장과 거의 같은 화면은 건너뛴다.

- 여러 사냥터, 여러 몹, 헬파이어/삼매 이펙트가 터지는 장면, 몹이 겹친 장면을 골고루 모은다.
- 처음엔 300~500장이면 충분하다. 비슷한 장면만 많으면 `폴더`를 눌러 지워도 된다.

## 2. 라벨링
`label.bat`을 실행하면 labelImg가 캡처 폴더를 연다.

1. 왼쪽 메뉴의 저장 형식 버튼을 **YOLO**로 바꾼다 (한 번만).
2. `W`를 누르고 몹 하나하나에 박스를 그리고 `monster`, 내 캐릭터는 `me`를 고른다.
3. `Ctrl+S`로 저장, `D`로 다음 장, `A`로 이전 장.
4. 몹이 없는 화면도 박스 없이 저장하면 배경 사진으로 쓰인다.

박스는 몹 몸통에 딱 맞게 그리고, 이름표나 체력바는 빼는 게 좋다.

## 3. 학습
`train.bat`을 실행한다 (`train.bat 50`처럼 에폭 수를 줄 수 있다).
라벨 있는 사진만 골라 학습 85% / 검증 15%로 나누고 학습한다.
NVIDIA 그래픽카드가 있으면 자동으로 GPU로 학습한다 (500장 100에폭에 수 분~수십 분). CPU로는 몇 시간 걸린다. 결과 모델은
`%USERPROFILE%\.baram_macro\detector\train\weights\best.pt`.

## 4. 확인
`predict.bat`을 실행하면 검증용 사진에 박스를 그린 결과 폴더가 열린다.
특정 사진이나 폴더를 넘길 수도 있다: `predict.bat C:\경로\사진.png`.
틀리게 잡는 장면을 캡처해 더 라벨링하고 다시 학습하면 정확도가 오른다.

## labelImg가 꺼질 때
labelImg는 python 3.10 이상에서 확대/스크롤 중에 꺼지는 경우가 있다.
그럴 땐 [X-AnyLabeling](https://github.com/CVHub520/X-AnyLabeling/releases) 실행 파일로 같은 폴더를 열고
`classes.txt`의 클래스로 박스를 그린 뒤 YOLO 형식으로 내보내면 된다 (사진과 같은 폴더, 같은 이름의 txt).

## 5. 매크로에서 쓰기
`best.pt`가 생기면 OCR 서버(`run_ocr_server.bat`)가 다음 요청부터 그 모델로 `/detect/`에 답한다 (다시 학습해도 서버를 다시 켤 필요 없다).
주술사 앱의 **몹 탐지** 줄에서 `▶`를 누르면 0.3초마다 몹과 내 위치를 읽고, `미리보기`로 박스를 확인할 수 있다
(빨강 몹, 초록 나, 굵은 빨강이 가장 가까운 몹).

탐지가 켜져 있으면 헬파이어는 가장 가까운 몹을 **마우스로 찍어** 저주를 건 뒤 그 대상에게 1 + Enter로 쓴다.
클릭이 끝나면 마우스는 원래 자리로 돌아간다. 탐지 결과가 없으면 예전처럼 방향키로 대상을 잡는다.
